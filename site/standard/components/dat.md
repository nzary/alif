<p>Data Literacy is one of the five components of AI literacy in the ALiF Standard. Every conforming implementation addresses all five, with emphasis that varies by professional role.</p>
<h2>Key elements</h2><ul><li>Data quality assessment</li><li>Data management practices</li><li>Analysis methodologies</li><li>Communication approaches</li></ul>
<h2>Example competencies</h2><ul><li>Evaluates quality and limitations of datasets</li><li>Manages data collection and processing appropriately</li><li>Analyzes and interprets data for decision-making</li><li>Communicates data insights through effective visualization</li></ul>
<h2>How it relates to the other components</h2><p>Data Literacy (DAT) as foundational substrate. Data literacy provides the conceptual foundation that the other four components draw upon. Technical Understanding requires grasping how data shapes AI behavior. Critical Evaluation requires assessing data quality to judge output reliability. Practical Application requires working with data inputs and outputs. Ethical Considerations requires understanding data privacy, bias, and representation. While DAT is not a prerequisite that must be completed before other components, weaknesses in data literacy constrain development across the framework.</p>
<h2>Sub-competencies (4)</h2>
<section class="subcomp" id="dat-1">
<h3>DAT.1 Data Understanding</h3><p>The ability to comprehend the nature, types, quality, and limitations of data that underlie AI systems. This sub-competency encompasses recognizing different data types and formats, evaluating data quality and identifying biases within datasets, understanding how data characteristics shape AI system behavior and outputs, and appreciating the constraints that data limitations place on AI reliability.</p>
<div class="table-wrap"><table><caption class="sr-only">Level descriptors for DAT.1</caption><thead><tr><th scope="col">Foundation (L1)</th><th scope="col">Intermediate (L2)</th><th scope="col">Advanced (L3)</th></tr></thead><tbody><tr><td>Recognizes common data types and formats. Evaluates basic data quality (completeness, obvious errors). Understands that AI outputs depend on training data. Identifies straightforward biases in datasets.</td><td>Assesses data quality using multiple criteria. Evaluates how data characteristics shape AI behavior. Identifies subtle biases and their potential consequences. Understands the relationship between data provenance and output reliability.</td><td>Develops data evaluation frameworks that others adopt. Creates data quality standards for organizational use. Leads initiatives to improve data understanding across teams. Designs approaches for identifying data limitations in novel AI applications.</td></tr></tbody></table></div>
</section>
<section class="subcomp" id="dat-2">
<h3>DAT.2 Data Collection and Management</h3><p>The ability to handle data responsibly throughout its lifecycle in AI-related contexts. This sub-competency encompasses collecting data using appropriate and ethical methods, organizing and storing data in accessible and secure formats, maintaining data quality and integrity over time, and adhering to privacy and security standards in data management.</p>
<div class="table-wrap"><table><caption class="sr-only">Level descriptors for DAT.2</caption><thead><tr><th scope="col">Foundation (L1)</th><th scope="col">Intermediate (L2)</th><th scope="col">Advanced (L3)</th></tr></thead><tbody><tr><td>Collects data using standard, ethical methods. Organizes data for accessibility and basic security. Follows established data management protocols. Maintains data integrity in routine tasks.</td><td>Implements structured data management procedures. Designs data collection approaches for specific purposes. Creates systems for maintaining data quality over time. Ensures compliance with privacy and security standards.</td><td>Develops data governance strategies that embed quality and ethics into organizational data handling. Creates data management methodologies that others adopt. Leads institutional data stewardship initiatives.</td></tr></tbody></table></div>
</section>
<section class="subcomp" id="dat-3">
<h3>DAT.3 Data Analysis</h3><p>The ability to analyze and interpret data in the context of AI use and AI-generated outputs. This sub-competency encompasses applying appropriate analytical methods to extract meaning from data, interpreting results with attention to uncertainty and limitations, using data analysis to evaluate AI system performance, and drawing defensible conclusions from data-driven evidence.</p>
<div class="table-wrap"><table><caption class="sr-only">Level descriptors for DAT.3</caption><thead><tr><th scope="col">Foundation (L1)</th><th scope="col">Intermediate (L2)</th><th scope="col">Advanced (L3)</th></tr></thead><tbody><tr><td>Performs basic data analyses using standard tools. Interprets simple analytical outputs. Identifies obvious patterns and anomalies. Recognizes when analysis results are unreliable.</td><td>Applies appropriate analytical methods for different data types. Interprets results with attention to uncertainty and limitations. Uses analysis to evaluate AI system performance. Draws defensible conclusions from evidence.</td><td>Develops analytical frameworks that connect data analysis to strategic decision-making. Creates methodologies for evaluating AI performance across complex, multi-variable contexts. Leads analytical initiatives that inform organizational AI strategy.</td></tr></tbody></table></div>
</section>
<section class="subcomp" id="dat-4">
<h3>DAT.4 Data Visualization and Communication</h3><p>The ability to represent and communicate data-driven insights effectively to relevant audiences. This sub-competency encompasses creating clear and accurate data visualizations, selecting appropriate visualization methods for different data types and audiences, interpreting and critically evaluating others’ data presentations, and communicating data-informed conclusions in ways that support decision-making.</p>

Interprets basic charts and graphs correctly. Communicates data findings in plain language. Recognizes misleading visual representations.</td><td>Designs effective visualizations for different audiences. Selects appropriate visualization methods for data types. Develops data communication strategies for professional contexts. Creates narratives that make data insights accessible.</td><td>Creates data communication systems that connect insights to decision-making at organizational scale. Develops visualization approaches that reveal patterns in complex AI-related data. Mentors others in effective data storytelling.</td></tr></tbody></table></div>
